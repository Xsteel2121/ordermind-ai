# OrderMind AI · Coffee Boom

Next.js App Router, React 19, TypeScript, Tailwind CSS 4, Lucide и Framer Motion. Презентационный сайт, демо заказа на RU/KK, полный каталог Coffee Boom, журнал и калькулятор экономики в тенге.

## Запуск и проверка

Node.js 22+, pnpm 11.25.0:

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
pnpm eval
pnpm build
```

Для Vercel: Next.js, Node.js 22.x, установка `pnpm install --frozen-lockfile`, сборка `pnpm run build`, Output Directory по умолчанию. Статический экспорт отключён: `/api/parse/` выполняется на сервере, остальные страницы предрендерены.

## Меню

`lib/menu.json` содержит все 249 позиций и цены из предоставленного `Coffee_Boom_Menu.pdf`. 23 категории находятся в `lib/categories.json`. Каждый SKU хранит ID, исходное название, синонимы RU/KK, цену, порцию и страницу источника. Названия блюд сохранены как в PDF. Подбор поддерживает казахские синонимы, количества, русские и смешанные фразы.

Источник — меню доставки Coffee Boom в Астане от 18.09.2026. Цены в зале и других филиалах могут отличаться. В документе нет условий добавок, поэтому они не объявлены включёнными в цену. Пожелания вроде овсяного молока и «без лука» сохраняются отдельными примечаниями. Сотрудник подтверждает доступность и вводит доплату за одну порцию. Итог считается только по каталогу и подтверждённым доплатам.

«Капучино» без объёма требует выбора между Single 300 мл за 1 400 ₸ и Boom 400 мл за 1 600 ₸. Демо не придумывает S/M/L, которых нет в источнике. Неизвестные блюда не подменяются похожими.

## Разбор текста и ИИ

Во время ввода локальный словарь показывает предварительный заказ через 320 мс. «Разобрать заказ» отправляет текст в серверный `POST /api/parse/`. Для сложных формулировок используется AI SDK 7 с Vercel AI Gateway и структурированным ответом. ID результата повторно проверяются по каталогу. Модель не назначает цены.

На Vercel аутентификация использует автоматически предоставляемый OIDC. При необходимости можно задать серверную переменную `AI_GATEWAY_API_KEY` в настройках Vercel. Для локальной проверки ИИ используйте переменные окружения или `.env.local`, который не входит в архив. Опциональная переменная `AI_GATEWAY_MODEL` выбирает модель. В этой версии по умолчанию используется `google/gemini-3.8-flash`, проверенная по живому списку AI Gateway 11.10.2026.

В проверке на Vercel 11.10.2026 Gateway ответил отказом доступа (403), поэтому успешный облачный разбор пока не подтверждён. Для его активации нужно обеспечить доступ к AI Gateway в выбранном аккаунте.

Если у аккаунта нет доступа/кредитов или запрос завершился ошибкой, интерфейс сообщает об этом и сохраняет локальный подбор. Ручное добавление из каталога всегда доступно. Обработка ограничена 1 500 символами, 20 строками, количеством 1–20, таймаутом 18 секунд и 8 облачными запросами в минуту на IP в пределах экземпляра функции. Этот ограничитель не является общим постоянным лимитом между всеми экземплярами Vercel; для массового пилота нужен общий лимит/WAF и контроль бюджета.

Аудио сайт не хранит. Кнопка голоса использует SpeechRecognition, запрашивает микрофон после нажатия и завершает сеанс через 25 секунд. Русский или казахский язык выбирается отдельно. Качество смешанной речи и поддержка API зависят от браузера; полноценная облачная ASR не подключена.

## Данные и маршруты

- `/` — презентация продукта.
- `/demo/`, `/staff/` — ввод речи/текста, уточнение вариантов, редактирование чека, подтверждение.
- `/menu/` — поиск, категории, цены и добавление в текущий заказ.
- `/analytics/`, `/report/` — журнал браузера, график, экспорт JSON.
- `/economics/` — сценарии, тарифы, изменяемые допущения, экспорт CSV.
- `/api/parse/` — серверный разбор сложных фраз.

Язык, тема, журнал и экономика хранятся в `localStorage` под ключом `ordermind-coffeeboom-v2`. Черновик текущего заказа — в `sessionStorage` под ключом `ordermind-draft-v2`: правки сохраняются при переходах и перезагрузке вкладки. Подтверждение защищено от повторного нажатия. Старый ключ `ordermind-v1` не удаляется; старый демонстрационный каталог заменён меню Coffee Boom.

## Сценарий показа

1. Введите «Бір капучино, овсяное молоко».
2. Выберите Single 300 мл или Boom 400 мл.
3. Уточните молоко у сотрудника, введите доплату или оставьте 0 и нажмите «Уточнено».
4. Подтвердите заказ. Проверьте сумму и состав в журнале.
5. Попробуйте «Екі куриных бургера, пиязсыз, и один фри»: два бургера и фри дают 8 400 ₸ до возможной доплаты.
6. В калькуляторе базовая чистая выгода — 269 000 ₸/месяц. Это расчётная модель, а не результат пилота.

## Пределы демонстрации

Касса и кухня не подключены. Подтверждение сохраняет демо-заказ в браузере. 2 000 ₸ на заказ с уточнением и стоимость обработки 8 ₸ — допущения финансовой модели; фактическая стоимость вызова ИИ может отличаться. Нет базы, общих журналов сотрудников, авторизации и реальной отправки заказа. Для пилота требуются проверка меню конкретного филиала, POS-интеграция, запись эталонных заказов с согласия участников и измерение качества на реальной речи.
